V364 Custom Color Printed Keycaps 6.0U spacebar row
===========================================================

These are the files that were submitted to MaxKeyboard.com to create
Custom Color Printed Cherry Keycaps for 104 keys.

Files Included:

* 104_6.0_ANSI_COLOR_TOP_PRINT_07_2019.svg
* 104_SIDE_PRINT_6.25X_COLOR_KEY_TEMPLATE.svg
* V364-Keyboard Layout-KLE.json
* V364-Keyboard.jpg
* V364-Main keycap scan.jpg

- Main keyboard keycaps are WHITE.
- Inverted-T cursor keycaps are GRAPHITE.
- Numeric Pad keycaps are LIGHT GREY.

- Top printing is in BLACK except for cursor keys (white).
- All Side printing is in 50% GREY. There is no side printing for numeric pad.
- All Top labelling is oriented to the top-left of the keycap.
- All Side labelling is centered.

- My keyboard does not have a function key row like normal pc keyboard.
  I have placed any key that does not fit onto this row in the template.
  Keys on this row must be relocated! They are NOT R4 slope!

- Keys are generally the correct size and place with the following exceptions:
  - "Run Stop" and "Shift Lock" on Row 4 (top) should be on Row 2.
  - "/" on Row 4 should be on Row 2.
  - "0" and "." on Row 1 are in the wrong location.
  - "Return" is on the correct Row 2 and size 2U but in the wrong location.

- Refer to pictures for layout:
  - Original keyboard had funny cursor arrows. These are blacked out and will be replaced
    with normal Inverted-T cursor.
  - The original 9U spacebar is not available so is replaced with a 6U plus two 1.5U keys.
  - The KLE JSON file was submitted earlier and is included in this zip file.
    It DOES NOT have the correct labelling!
  - The "Main keycap scan" jpg file shows the layout, tops, and fronts of an actual keyboard
    (left side of V364 keyboard).
